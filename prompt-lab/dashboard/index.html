How the data gets here mock flow

1 · ForkParticipant forks unext-learning/prompt-lab-cohort
2 · CommitCourse page exports progress.json; participant commits it to progress/<name>.json
3 · AggregateA GitHub Action merges all progress/*.json into data.json on every push
4 · PublishGitHub Pages serves this page, which reads data.json. No server, no licence cost.
