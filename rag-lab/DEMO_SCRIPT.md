## LIVE — 13 minutes

### ACT 1 · The problem (2.5 min)

1. Tab **3 · Ask**, **Compare with baseline** ON, Preset = **Baseline (naive RAG)**
2. Type: `What is the minimum password length?` → **Ask**

**On screen:** both columns say **8 characters**, source **KB-001 v1**, red *Top source is WRONG*.

**Say:** *"This is a help assistant for an IT team. It just told the user 8 characters. The real policy
is 14 — it quoted a document that was retired in March, and it sounded completely sure of itself."*

3. Sidebar → **Preset** = **FDE-grade (all on)** → **Ask** again

**On screen:** right column **14 characters**, source **KB-001 v2**, green.

**Say:** *"Same question, same documents, same AI. What changed is how it was built. Teaching people to
tell those two apart is the course. Now — how do I know each of twenty-five people actually learned
it?"*

> Leave the Preset on **FDE-grade** for the rest of the demo.

## IF SOMETHING BREAKS

| Symptom | Fix |
|---|---|
| *"belongs to X, not Y"* | Name differs between Streamlit and the course page. Fix the sidebar, regenerate. **Say:** *"That is the binding working."* |
| *"generated before this stage was unlocked"* | You reset the course page after generating. Regenerate. |
| Stage will not unlock | Needs **quiz passed AND proof validated** — check the three chips. |
| Stage 2 proof shows no bonuses | Preset must be **FDE-grade** (section chunking) and the upload must still be loaded. |
| Trainer skip button missing | URL is missing `?trainer=1`. Reload; progress is kept. |
| Everything is on fire | `dashboard\index.html` opens standalone with the full cohort. Narrate from there. |
